# Installation

Requires Windows 10/11, 64-bit. Packaged downloads include Python. A GPU is optional.

## Windows installer — recommended

1. Download [Image Draw Bot v1.0.145-rc5 Setup](https://github.com/Vxiey/Image-Draw-Bot/releases/download/v1.0.145-rc5/ImageDrawBot-1.0.145-rc5-Windows-x64-Setup.exe).
2. Close any running Image Draw Bot instance and run Setup.
3. Open **Image Draw Bot** from the Start menu.
4. Open **Get started** in the header, then follow [First Use](First-Use).

## Portable ZIP

Download the [Windows ZIP](https://github.com/Vxiey/Image-Draw-Bot/releases/download/v1.0.145-rc5/ImageDrawBot-1.0.145-rc5-Windows-x64.zip), extract the entire archive, and run **ImageDrawBot/ImageDrawBot.exe**. Keep the supporting files, including `_internal`, together. Do not run inside the ZIP or move only the executable.

## Source checkout

Source runs require 64-bit Python 3.11+ and internet for dependency installation. Follow the [source instructions](https://github.com/Vxiey/Image-Draw-Bot#run-from-source). Source code archives are different from the packaged Windows ZIP.

## Verification and publisher

[SHA-256 checksums](https://github.com/Vxiey/Image-Draw-Bot/releases/download/v1.0.145-rc5/ImageDrawBot-1.0.145-rc5-SHA256.txt) verify downloaded file integrity. Published packages are unsigned: Windows may show an unknown-publisher warning or block execution. Checksums are not publisher signatures.
