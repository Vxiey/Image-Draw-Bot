# Image Draw Bot v1.0.146-rc4: 100 implemented improvements

This release implements the 100 behavior changes below. The IDs are unique and
continuous from 001 to 100. Version bumps, documentation, formatting and added
tests are not counted as improvements; tests provide evidence for the behavior
changes. Related fixes are grouped where they solve the same problem.

The tables identify the implementation and regression coverage. The linked
area reviews include compatibility details, test scope and remaining limits.

## Integration verification

The release gates exercise source-package hygiene, the full regression suite,
5,000 soak cycles, dependency audits, native Windows APIs, the built GUI and
native drag and drop, package checksums/manifest validation, and a silent
install/self-test/uninstall round trip. Windows-specific tests skipped on a
Linux development host remain mandatory Windows CI checks. The native DXGI
probe also runs in source, frozen and installed application self-tests.

GPU dispatch and numerical regressions use controlled compute fixtures where
physical GPU hardware is unavailable. They do not certify every driver or GPU.
Recovery retains legacy schemas and never restores mouse-input authorization.
Profile file operations roll back reported filesystem errors; they are not
power-loss-atomic across multiple files. The metadata request budget is checked
between redirects/chunks, with separate socket timeouts during active reads.

## Antivirus investigation

The GPU-discovery PowerShell process has been removed. Paint's explicit UI
Automation operation still uses its existing readable PowerShell helper, and
the application still loads its bundled Python runtime and native extensions.
The executable and installer remain unsigned because no trusted signing
identity is configured. These changes improve observable program behavior and
security; they do not promise a zero-detection antivirus result or establish
the cause of every external sandbox alert.

See the [artifact-specific investigation](ANTIVIRUS-REVIEW-2026-11.md) and
[release notes](../RELEASE-NOTES-v1.0.146-rc4.md). A scan of an earlier release
hash is not a scan of the RC4 artifacts.
