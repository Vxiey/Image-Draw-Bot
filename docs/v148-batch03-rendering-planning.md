# 1.0.148 batch 03: rendering and planning

This ledger records **38 distinct behavior groups**, RP01–RP38, against local Git baseline `2fb7abf470a4ef498df9c53f42cddda62d8b652b`. Tests, documentation, model-version changes, shared call-site integrations and benchmark artifacts do not add to that count. This is a bounded batch of engine changes, not a claim that every defect in the application has been found.

The batch changes plan construction, cost estimates, image analysis, pure raster simulation and previews. It does not send desktop input or relax target, calibration, arming or authorization checks. Several previews intentionally change because they previously did not depict the pixels covered by their plans. The raster optimizations otherwise retain exact output for their supported models: integer Bresenham and rounded interpolation remain separate models.
