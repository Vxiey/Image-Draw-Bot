# Extra Fast physical sampling acceptance

This is a focused correction, not evidence that the remaining 14-item batch or
900/900 release scope is complete.

## Reproduction

A recognizable Grace Hopper photograph (Matplotlib's bundled `grace_hopper.jpg`,
resized to 154x180), Extra Fast, Photo / Shaded, Gartic Phone, 480x480 target,
fixed 2px brush and no calibrated Fill produced sparse maze-like lines in the
native simulated preview. The old 57x67 analysis raster put physical centerlines
about 7px apart, while the brush remained 2px. All source rows being covered did
not mean the actual canvas was covered.

Old simulation: 690 paths, 24.2076% native coverage, 147317 missing target pixels,
28.10s raw ETA. This was a Manual-mode planner invocation, not an active deadline.

## Correction and bounded behavior

Explicitly selected Extra Fast fixed-brush plans now require sufficient analysis-grid density for the
real brush width. The existing memory/pixel cap is unchanged. If the necessary
aspect-preserving grid cannot fit, planning reports an actionable error rather
than returning the sparse drawing. EXIF-oriented dimensions and final rounding
are accounted for. Verified multi-brush plans retain their separately proven
native packing route; their smallest brush is not imposed globally.

For explicitly selected Extra Fast, an exact native pack is preferred over a physically inexact connected-run
candidate. At unit scale with a 1px brush, connected-run candidates remain valid
cost competitors. Auto and generic adaptive cost/density policies are unchanged.

## Verification and limits

A post-fix photo simulation with explicit Custom 120s budget visibly preserves
the face, cap, glasses, uniform and flag rather than maze-like fragments. It has
3535 paths, 65.3285% native coverage and 114.33s raw ETA. Its conservative cold-start
projection is 132.41s, so this is **not** proof of fitting a real 120s game round.
Budget selection and uncertainty remain distinct from physical coverage.

A synthetic pixel-art house remains recognizable. With an explicit Custom 120s
budget it selects 390 paths, 106.82s raw ETA and 134.72s cold-start projection.
The earlier 257.50s raw estimate used legacy Manual mode, which intentionally
leaves adaptive deadline scheduling inactive; it was not a demonstrated timer bug.

All images described here are local simulated previews. No actual Gartic/Paint
mouse execution or wall-clock ETA measurement was performed. The model assumes
its documented square brush footprint; real round/antialiased brush fidelity and
final same-version installer upgrade still require acceptance checks.
